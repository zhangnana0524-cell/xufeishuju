# 续费数据看板

一个交互式的班级续费数据分析看板，用于实时查看和分析教学班级的续费情况。

## 功能特点

- 📊 **实时数据分析**：上传Excel文件，即时生成统计数据
- 📈 **多维度图表**：按级别、教师、班级等维度展示续费数据
- 📑 **详细数据表**：查看教师和班级的详细续费统计
- 💾 **数据本地保存**：使用localStorage保存上传的数据
- 📥 **导出功能**：支持将统计数据导出为CSV格式
- ⚙️ **智能数据过滤**：自动排除退费/休学学生，确保分析数据准确
- 🎨 **响应式设计**：完全适配各种屏幕尺寸

## 使用方法

### 本地开发

1. 安装依赖
```bash
npm install
```

2. 启动开发服务器
```bash
npm run dev
```

3. 打开浏览器访问 `http://localhost:5173`

### 上传数据

1. 点击上传区域或拖拽Excel文件
2. 选择包含续费数据的Excel文件（.xlsx或.xls）
3. 等待文件加载和数据处理
4. 查看生成的看板和报表

### Excel文件格式要求

Excel文件需要包含以下列：
- `级别` - 学生级别
- `Batch Name` - 班次名称（可选）
- `Classes Name` - 班级名称
- `带班老师姓名` - 授课教师
- `教辅老师名称` - 教学助理（可选）
- `student_id` - 学生ID
- `续费状态` - 续费状态

**续费状态值说明：**
- **已续费**：自动识别包含"已续费"、"续费"的状态
- **未续费**：自动识别"未续费"、"未"等状态
- **联报**：自动识别"联报"状态
- **排除状态**（不计入统计）：自动识别并排除包含"退费"、"休学"、"已退"、"已休"的状态

### 构建生产版本

```bash
npm run build
```

## 技术栈

- **React 18** - UI框架
- **Vite** - 构建工具
- **Recharts** - 数据可视化图表库
- **xlsx** - Excel文件解析
- **Tailwind CSS** - 样式框架
- **DaisyUI** - UI组件库

## 部署

### Vercel部署（推荐）

1. 将项目推送到GitHub
2. 在Vercel（https://vercel.com）上导入项目
3. 配置项目设置：
   - Framework: Vite
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. 点击"Deploy"

### 其他平台

项目也可以部署到：
- Netlify
- GitHub Pages（需要配置base URL）
- 任何支持Node.js的服务器

## 数据隐私

- 所有数据处理均在浏览器本地进行
- 不会将任何数据发送到服务器
- 数据仅保存在浏览器的localStorage中
